How to deploy on Railway (one-time setup)
1
Create a free GitHub account at github.com if you don't have one.
2
Create a new repository on GitHub. Name it morning-sms. Upload all the project files (server.js, dashboard.html, package.json) into it.
3
Sign up for Railway at railway.app using your GitHub account.
4
Create a new project in Railway → "Deploy from GitHub repo" → select your morning-sms repo.
5
Add these environment variables in Railway under your service → Variables tab:
AT_USERNAME → your Africa's Talking live app name
AT_API_KEY → your live API key
HER_NAME → her first name (e.g. Ama)
HER_PHONE → her number (e.g. +233244123456)
SEND_TIME → time to send (e.g. 07:00)
SEND_DAYS → every | weekdays | weekdays+sat
ROTATION → sequential | random
6
Railway redeploys automatically. Once deployed, open your Railway URL — this exact dashboard will be live. Add your quotes, hit "Send test SMS" and confirm she gets it. That's it — it runs forever! 🎉
